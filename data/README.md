# Dataset

`sample_traffic.csv` is **synthetic** (generated by `ml/generate_sample_data.py`) and only lets you run the pipeline offline.

## Real dataset: CIC-IDS2017 (MachineLearningCSV)
1. Visit https://www.unb.ca/cic/datasets/ids-2017.html and download **MachineLearningCSV.zip**.
2. Extract the 8 CSV files into `data/cicids2017/`.
3. Train: `python ml/train_classifier.py --data data/cicids2017 --model xgboost` (needs ~16 GB RAM; use `--model rf` otherwise).
